## Reporting a vulnerability

Report it privately, never in a public issue:

- through [GitHub Security Advisories](https://github.com/AxsionDev/Lunos/security/advisories/new)
- by email to security@lunos.tech

See [`SECURITY.md`](https://github.com/AxsionDev/Lunos/blob/dev/SECURITY.md).

## Release and support policy

Each release gets **security fixes for 6 months from its release date**, starting with v1.18.43. Releases before v1.18.43 have no support period. A security fix ships as a new release, and its GitHub Security Advisory names the affected versions and the release that fixes them.

To see whether your release is still supported, check its date on [GitHub Releases](https://github.com/AxsionDev/Lunos/releases) or [lunos.tech/changelog](https://lunos.tech/changelog): support ends 6 months after it. When a newer release exists, Lunos says so at startup (`There is a new version: … please run "lunos update"`), and `lunos update` moves to it.

The policy is in [CRA readiness](https://github.com/AxsionDev/Lunos/blob/dev/docs/trust/cra-readiness.md#security-support-period).
