Save one durable fact to long-term memory, so later sessions know it without rediscovering it: who owns what, a decision and its reason, a convention this project follows, a gotcha that cost time.

A person approves every fact before it is stored. Memory refuses:
- anything in a turn that used webfetch, websearch, an MCP resource, or read a file outside this project. Memory never stores outside content, so remember facts from the user's own words or this project's files before fetching anything;
- anything shaped like a key, token or password.

Keep each fact to one self-contained sentence that will still make sense months from now. Don't save things that are already in the code or in AGENTS.md, and don't save task progress.

Say whether a fact is `observed` (the user said it, or you read it in a project file) or `inferred` (you concluded it); inferred facts are labelled as such when recalled. If a fact makes a recalled fact untrue, pass that fact's id as `replaces`: a person confirms, and the old fact is kept as outdated instead of being recalled. Use `expires` for facts that are only true until a known date.
