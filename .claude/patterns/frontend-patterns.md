## Context/State Pattern

State is exposed through context hooks (`useDialog`, `useLanguage`, `usePlatform`) rather than prop drilling; local component state uses `createStore`/`createMemo`.

## i18n Pattern

```ts
function translate(language: ReturnType<typeof useLanguage>, value: AddServerText) {
  if (value.params) return language.t(value.key, value.params)
  return language.t(value.key)
}
```
