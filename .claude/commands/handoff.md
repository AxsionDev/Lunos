# /handoff

Generate a handoff document for agent transition.

## Purpose

Prepares for transition to a different agent by generating a comprehensive handoff document and updating session state.

## Usage

```
/handoff
/handoff backend-developer
```

## Arguments

- `$ARGUMENTS` (optional) - Recommended next agent type

## What It Does

1. **Trigger compaction** if needed (to capture recent work)
2. **Generate handoff.md** with complete context
3. **Update session.yaml** agent chain
4. **Set session status** to `handoff_pending`
5. **Report handoff ready**

## Instructions for Claude

When the user runs `/handoff`:

1. Verify active session exists

2. **Compact if needed**:
   - Check if messages since last compaction > threshold
   - If so, run compaction first

3. **Load current state**:
   - `session.yaml` - metadata, agent chain
   - `tasks.yaml` - task status
   - `decisions.yaml` - recent decisions
   - `context.yaml` - compacted context

4. **Determine recommended next agent**:
   - If user specified, use that
   - Otherwise, infer from blocked tasks or next tasks

5. **Generate handoff.md**:

```markdown
# Agent Handoff: {session name}

**Session ID:** {session-id}
**Generated:** {ISO timestamp}
**Previous Agent:** {current agent from chain}
**Recommended Next Agent:** {next agent}

---

## Quick Context

{1-2 paragraph summary of what's being worked on and current state}

---

## What's Been Done

{For each completed task:}
- [x] {task title} ({task-id})

{Brief summary of key accomplishments}

---

## What's Next

{For each pending/in_progress task in priority order:}
1. **{task title}** ({task-id})
   - Status: {status}
   - Assigned: {agent}
   {If blocked: - Blocked by: {reason}}

---

## Key Decisions to Respect

{For each key decision:}
1. **{decision title}** ({decision-id})
   - {decision summary}
   - Rationale: {brief rationale}

---

## Important Files

**Frontend:**
{List frontend files from key_files}

**Backend:**
{List backend files from key_files}

**Config/Other:**
{List other files}

---

## Current Blockers

{If any blocked tasks or blockers:}
- {blocker description}

{If no blockers:}
No current blockers.

---

## Constraints

{List from context.yaml constraints:}
- {constraint 1}
- {constraint 2}

---

## How to Resume

1. Read the task registry:
   `.agent-state/sessions/{session-id}/tasks.yaml`

2. Check compacted context:
   `.agent-state/sessions/{session-id}/context.yaml`

3. Review recent decisions:
   `.agent-state/sessions/{session-id}/decisions.yaml`

4. Run `/state-resume` for automatic context injection

---

## Session Metrics

| Metric | Value |
|--------|-------|
| Tasks Completed | {count}/{total} |
| Decisions Made | {count} |
| Files Modified | {count} |
| Compactions | {count} |
| Duration | {calculated from timestamps} |

---

*Generated by State Manager*
```

6. **Write handoff.md**:
   - Location: `.agent-state/sessions/{session-id}/handoff.md`

7. **Update session.yaml**:

```yaml
status: "handoff_pending"

agent_chain:
  - agent: "{previous agent}"
    started_at: "{start time}"
    ended_at: "{now}"
    handoff_reason: "user_initiated"
    tasks_completed: ["{list of completed task IDs}"]
```

8. **Report**:

```
Handoff Prepared
─────────────────────────────────────────────────────────────

Session:           {session-id}
Previous Agent:    {agent}
Recommended Next:  {agent}

Handoff document:  .agent-state/sessions/{session-id}/handoff.md

Summary:
  ✓ Tasks completed: {count}
  → Tasks remaining: {count}
  ⊘ Blocked tasks:   {count}

Key decisions preserved: {count}
Context compacted: {yes/no}

─────────────────────────────────────────────────────────────
Next: New agent should run /state-resume to load context
```

## Output

Confirmation of handoff document creation with summary and next steps.
