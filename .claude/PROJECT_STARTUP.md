# Project Startup Guide

> Generated by project-startup-generator. Please review and adjust as needed.
> This is `opencode`: a Bun/TypeScript monorepo for a CLI/TUI AI coding agent. It is **not** a
> classic frontend+backend web app — there is no hosted API server meant to be started standalone.
> `packages/server` is an embedded Effect HTTP layer consumed by `packages/opencode`/`packages/cli`,
> not a separately-run product.

## Quick Start

### Install (root, once)
- **Install:** `bun install` (packageManager pinned: `bun@1.3.14`)
- **Postinstall:** runs `fix-node-pty` in `packages/core` automatically

### CLI / Core Product
- **Path:** `packages/opencode` (entrypoint), `packages/cli` (bin: `ratio`), `packages/tui`
- **Start:** `bun run dev` (root) → `bun run --cwd packages/opencode src/index.ts`
- **Notes:** this is the actual product; there is no separate "backend URL" to browse to

### Frontend — Desktop/Web App (`packages/app`)
- **Framework:** SolidJS + Vite
- **Path:** `./packages/app`
- **Install:** `bun install` (root workspace install covers this)
- **Start:** `bun run dev:web` (root) or `bun --cwd packages/app dev`
- **URL:** http://localhost:3000 (configured in `packages/app/vite.config.ts`)

### Frontend — Desktop shell (`packages/desktop`)
- **Start:** `bun run dev:desktop` (root)

### Frontend — Docs site (`packages/web`)
- **Framework:** Astro + Starlight + SolidJS islands
- **Path:** `./packages/web`
- **Start:** `astro dev` (via package script `dev`)
- **URL:** http://localhost:4321 (Astro default — no port configured in `astro.config.mjs`)

### Frontend — Console app (`packages/console/app`)
- **Start:** `bun run dev:console` (root) — raises `ulimit -n 10240` first

### Frontend — Stats app (`packages/stats/app`)
- **Start:** `bun run dev:stats` (root) — runs via `sst shell --stage=production`

### Frontend — Storybook (`packages/storybook`)
- **Start:** `bun run dev:storybook` (root)

### Backend (embedded HTTP layer)
- **Framework:** Effect `HttpApiBuilder` (`effect/unstable/httpapi`) — not Express/Hono/ASP.NET
- **Path:** `./packages/server` (route/handler definitions), `./packages/protocol` (API contract), `./packages/core` (domain logic)
- **Dependency direction:** Schema → Core/Protocol → Server. Client code may depend on Schema/Protocol but never Core/Server. Do not invert this.
- **Start:** not run standalone — started in-process by `packages/opencode`/`packages/cli`

### Database
- **ORM:** Drizzle ORM (`drizzle-orm/sqlite-core`)
- **Engine:** SQLite, via `@effect/sql-sqlite-bun` (Bun runtime) / `effect-sqlite-node` (Node runtime), selected through the `#db` import map (`packages/opencode/package.json` → `src/storage/db.bun.ts` vs `db.node.ts`)
- **Schema location:** colocated `*.sql.ts` files per domain in `packages/core/src/**` (e.g. `session/sql.ts`, `credential/sql.ts`, `project/sql.ts`)

## Prerequisites
- **Bun `1.3.14`** (pinned via `packageManager`; no `.nvmrc`/`.node-version` found)
- No `global.json`, `.python-version`, or `docker-compose.yml` found — none required
- No `.env.example` found — no documented required environment variables; check `globalEnv`/`globalPassThroughEnv` in `turbo.json` (`CI`, `OPENCODE_DISABLE_SHARE`) if you hit config gaps

## Environment Setup
No `.env` setup is required to run the CLI. If you need cloud/AWS access for stats/console work: `bun run sso` (`aws sso login --sso-session=opencode --no-browser`).

## Codegen Gotcha
After changing the public Protocol or Server `HttpApi`, run `bun run generate` from `packages/client`. **Never** hand-edit `src/generated` or `src/generated-effect`.

## Common Commands
| Task | Command |
|------|---------|
| Install deps | `bun install` (from repo root) |
| Run tests | `cd packages/<pkg> && bun test` — **never from repo root** (root `test` script is a deliberate guard: `do not run tests from root`) |
| Typecheck (whole repo) | `bun run typecheck` (root → `bun turbo typecheck`) |
| Typecheck (single package) | `cd packages/<pkg> && bun typecheck` — never call `tsc` directly |
| Build | `bun run build` (root → `bun run script/build.ts`) |
| Lint | `bun run lint` (`oxlint`, config: `.oxlintrc.json`) |
| Regenerate legacy JS SDK | `./packages/sdk/js/script/build.ts` |
